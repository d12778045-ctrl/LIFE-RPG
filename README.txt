LIFE RPG — Android/PWA project

Что внутри:
- index.html — приложение
- manifest.webmanifest — параметры установки
- sw.js — кеширование оболочки приложения

ВАЖНО:
1. Для камеры обязателен HTTPS (или localhost). Открытие index.html как локального файла не даст доступ к камере.
2. Размести содержимое папки на HTTPS-хостинге (например, GitHub Pages, Netlify или другом статическом хостинге).
3. Открой опубликованный HTTPS-адрес в Google Chrome на Android.
4. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран».
5. Разреши доступ к камере при первом запуске тренировки.

Камера:
- Видео обрабатывается в браузере на устройстве; аудио не запрашивается.
- MediaPipe и модель загружаются с внешних CDN/Google Storage, поэтому при блокировке этих доменов камера не запустится.
- Алгоритм подсчёта повторений — ориентировочный, не является проверкой безопасности техники или заменой тренера.
- Для отжиманий/приседаний камера должна видеть нужные суставы; сейчас используется упрощённая геометрия.

Сохранения:
- Прогресс хранится в localStorage этого браузера/установки. Между устройствами не синхронизируется.
- Не очищай данные браузера, иначе локальный прогресс может пропасть.

Это исходный проект PWA, а не APK. Самостоятельно установить APK или развернуть сайт из этого чата я не могу.
